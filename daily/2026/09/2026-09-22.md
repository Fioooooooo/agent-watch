## 完整材料

### 1. Plugin4Shell：插件 SHA 固定链路存在可绕过的供应链风险

- **Source**：AIR Security
- **Published**：2026-09-17（公开披露；今日继续作为开放发现高价值材料复核）
- **Topics**：Coding Agent、Harness、Plugin、Skills、Supply Chain、Permissions、Sandbox
- **Priority**：P0
- **Original**：https://www.air.security/blog-posts/plugin4shell
- **What changed**：公开披露影响四类主流 Coding Agent 插件机制的高影响漏洞。攻击者控制插件仓库时，可以利用 Git ref 解析与 SHA pinning 校验之间的缺口，让 Agent 取得与审查版本不同的代码；在后台自动更新存在时，攻击可在无用户交互情况下发生。
- **Technical details**：问题位于 Agent 侧的安装/更新实现，而非市场审核本身。仅保存一个目标 SHA 不足以证明实际执行对象就是该 commit；安装流程需要对 resolved commit、HEAD、本地工作树和来源仓库进行一致性校验。插件以开发者权限执行，因此影响边界取决于 Agent 所在工作区、凭证、网络访问和宿主环境权限。
- **Why it matters**：这把 Agent Harness 的供应链安全从“插件来源与版本固定”推进到“可验证的软件物料证明 + 运行时权限隔离”。同样的设计问题会外溢到 Skills、MCP server、Hooks 和其他可执行扩展；后续应观察各厂商是否补充 commit 证明、来源锁定、更新前重验证、隔离执行和管理员策略。
- **Worth reading full original**：是
