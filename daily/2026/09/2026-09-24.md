## 完整材料

### 1. OpenAI 发布 GPT-6 Sol / Luna：把 Agent 成本曲线纳入模型产品设计

- **Source**：OpenAI models
- **Published**：2026-09-23
- **Topics**：Model Release、Coding Agent、Computer Use、Inference Efficiency、Agent Economics
- **Priority**：P1
- **Original**：https://openai.com/index/introducing-gpt-6-sol-and-luna/
- **What changed**：GPT-6 Sol 与 GPT-6 Luna 发布，官方强调更低价格、更高编码与 Computer Use 能力，以及更高的任务效率。
- **Technical details**：官方给出的重点包括：缓存与推理效率改进；API 价格相较 GPT-5.6 promotional pricing 下调 50%；在 FrontierCode、DeepSWE、OSWorld 等评测中，Sol / Luna 面向 coding、long-running workflow 与 computer use 展示更高的成本效率。
- **Why it matters**：当模型成本、缓存命中、调用次数和任务完成成本被统一展示后，Harness 的模型路由、上下文复用、重试策略和多 Agent 拆分都会受到直接影响。模型层的效率开始成为 Harness 架构约束，而不是单独的模型指标。
- **Worth reading full original**：是

### 2. Anthropic 发布 Claude Opus 5.5：长任务 Agent 的单位任务成本下降

- **Source**：Anthropic models
- **Published**：2026-09-23
- **Topics**：Model Release、Agentic Coding、Long-running Agents、Error Recovery、Cost Efficiency
- **Priority**：P1
- **Original**：https://www.anthropic.com/claude-opus-5-5
- **What changed**：Claude Opus 5.5 发布，官方强调 agentic coding、computer use、knowledge work，以及相较 Opus 5 更低的价格和更快的输出。
- **Technical details**：官方公布输入与输出单价下降、cache reads 成本下降、输出速度提升，并强调在多步任务中使用更少步骤和更少 token，同时能更快从错误中恢复。官方还提供 Terminal-Bench、FrontierCode 和 CursorBench 等 coding 评测数据。
- **Why it matters**：对 Harness 而言，模型的“每次调用成本”正在被“每个完整任务成本”取代。更少的步骤、更强的错误恢复和更低的缓存读取成本，会改变编排层对 worker 数量、上下文重放和检查点频率的设计。
- **Worth reading full original**：是

### 3. GitHub Copilot：可观测性、工具审批与组织级 Agent 治理进入产品层

- **Source**：GitHub Copilot
- **Published**：2026-09-22
- **Topics**：Agent Harness、Observability、Tool Governance、MCP、Skills、Plan Mode
- **Priority**：P1
- **Original**：
  - https://github.blog/changelog/2026-09-22-opentelemetry-in-the-github-copilot-app/
  - https://github.blog/changelog/2026-09-22-new-features-and-improvements-in-copilot-for-jetbrains/
- **What changed**：Copilot app 增加 OpenTelemetry 配置；Copilot for JetBrains 增加 AI-assisted tool approvals、组织级 Skills 与 custom instructions、Codex plan mode，以及持久化 MCP 工具控制。
- **Technical details**：企业管理员可以通过 managed settings 配置 OTel，将 Agent session、模型请求和工具调用导出到兼容的监控系统；JetBrains 端支持低风险工具自动批准、高风险操作继续请求用户决策，支持回退到较早消息并同步回滚文件变化，还能控制内置 GitHub MCP Server 与单个 MCP 工具。
- **Why it matters**：Agent Harness 的企业化重点开始从单纯的模型接入转向三类基础能力：执行追踪、风险分级审批、组织级工具与指令治理。这些能力决定了 Agent 能否进入可审计、可控和可运营的开发流程。
- **Worth reading full original**：是
