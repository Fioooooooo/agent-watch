### 2. Qwen Code v0.24.5：运行时证明、工具追踪与长会话成本控制继续下沉

- **Source**：Qwen / Qwen Code
- **Title**：`v0.24.5`
- **Published**：2026-09-24
- **Topics**：Runtime Attestation、Observability、Workspace Recovery、Context Engineering、Prompt Cache
- **Priority**：P1
- **Original**：[Qwen Code Releases](https://github.com/QwenLM/qwen-code/releases)
- **What changed**：新增 managed runtime attestation worker；记录每次工具调用开始时间；workspace 注册后恢复 `serve.channels`；相邻版本继续完善 size-triggered microcompaction，清理旧 tool results 并保留 provider prompt-cache 复用。
- **Technical details**：runtime attestation 为托管执行环境增加可验证身份；tool-call start time 为端到端延迟、并发和失败恢复提供更细粒度的时间基线；microcompaction 通过低水位回收旧工具结果，避免频繁重写后续 conversation prefix。
- **Why it matters**：长任务的成本已不只是模型调用价格，还包括工具等待、上下文膨胀、缓存命中率和执行环境可信度。Qwen Code 正在把这些指标直接纳入 Agent runtime。
- **值得阅读全文**：是
