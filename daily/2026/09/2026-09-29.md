NVIDIA 于 2026 年 9 月 28 日发布 Open Agent Safety Platform，组合了 OpenShell 与 Sentry：OpenShell 在运行时追踪 Agent 行为并执行资源与权限策略，Sentry 通过独立的 BlueField-4 DPU 作为带外监控与隔离层，在检测到越界行为时执行隔离。该设计把 Agent 的工具、数据、API、身份与遥测控制从应用内策略推进到隔离执行环境和硬件信任域。citeturn294255search2

### 1. NVIDIA Open Agent Safety Platform：Agent 安全从应用层沙箱扩展到全栈控制面

- **Source**：NVIDIA
- **Title**：NVIDIA Launches Open Agent Safety Platform to Secure Agents From Testing to Deployment
- **Published**：2026-09-28
- **Topics**：Agent Security、Sandbox、Policy Enforcement、Runtime Attestation、Long-running Agent、Hardware Isolation
- **Priority**：P1
- **Original**：https://investor.nvidia.com/news/press-release-details/2026/NVIDIA-Launches-Open-Agent-Safety-Platform-to-Secure-Agents-From-Testing-to-Deployment/default.aspx
- **What changed**：NVIDIA 发布 Open Agent Safety Platform，包含 OpenShell 开源软件和 Sentry 参考系统设计。citeturn294255search2
- **Technical details**：OpenShell 提供安全运行时边界，追踪 Agent 动作并执行对文件、网络、工具、API 和服务的策略；Sentry 在独立的 BlueField-4 DPU 上运行，以带外方式持续监控 Agent 行为，并在越界时执行隔离。官方还提到通过 DOCA 提供 Agent 身份验证、可证明遥测和零信任策略控制。citeturn294255search2
- **Why it matters**：传统 Harness 通常把权限、沙箱和审计放在 Agent 进程或宿主操作系统之内。带外监控与硬件信任域把“Agent 能否修改或绕过自己的安全控制”转化为系统架构问题，直接影响多 Agent、长期运行和高权限工具场景的设计。
- **值得阅读全文**：是

### 2. Claude Sonnet 5.5 进入 GitHub Copilot：模型效率开始直接改变 Coding Agent 调度成本

- **Source**：GitHub Copilot
- **Title**：Claude Sonnet 5.5 in GitHub Copilot
- **Published**：2026-09-28
- **Topics**：Coding Agent、Model Routing、Tool Use、Token Efficiency、Copilot CLI
- **Priority**：P1
- **Original**：https://github.blog/changelog/2026-09-28-claude-sonnet-5-5-in-github-copilot/
- **What changed**：Claude Sonnet 5.5 在 GitHub Copilot 中正式可用，覆盖 IDE、Copilot CLI、GitHub Copilot coding agent、Copilot app 和 Web 等入口。citeturn294255search0
- **Technical details**：GitHub 表示其在早期测试中完成编码任务所需的步骤、Token 和工具调用更少，速度更快，同时编码表现接近 Claude Sonnet 5。citeturn294255search0
- **Why it matters**：对 Coding Agent 而言，模型能力不再只体现在单次回答质量，还体现在完成同一任务所需的 loop 次数、上下文消耗和工具调用数量。模型路由、预算控制、超时设计和任务分解策略会因此改变。
- **值得阅读全文**：持续观察
