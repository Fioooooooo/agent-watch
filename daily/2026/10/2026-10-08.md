# Agent 一手情报｜2026-10-08

## 每日摘要

本次扫描归档 **9 条高价值材料**，覆盖状态为 **`coverage incomplete`**。Windsurf 官方入口仍无法与独立的 Windsurf 最新发布入口建立可靠对应关系；Qwen、DeepSeek、Kimi、Z.ai 四个模型来源本次未取得符合“打开官方模型最新入口并读取连续 3～5 条”的证据，因此不能解释为“无更新”。

### 1. Coding Agent 的安全边界开始从“权限确认”转向本机强制 sandbox

GitHub Copilot 把本地 sandboxing 正式推向 GA，覆盖 Copilot CLI、Copilot App 和 VS Code Agent Host。它通过 MXC 将统一 sandbox policy 映射到 Windows、macOS、Linux，可以限制文件、网络、Git 凭据、GitHub CLI 凭据以及本地 MCP / language server，并允许企业策略强制启用。citeturn9view0

Codex 0.161.0 同时继续强化 background task 权限继承、sandbox、remote agent tree、thread recovery 和 multi-agent message board；Claude Code 2.1.293 则修复 context compaction、MCP connection、后台 session 和 subagent tool 边界。三者共同指向一个 Harness 变化：**持续自主执行要求安全边界进入 execution runtime，而不是只依赖单次 tool approval。** citeturn8view0turn9view1

### 2. 小模型开始成为 Agent Harness 的高频子任务执行层

Anthropic 发布 Claude Haiku 5.5，直接定位 summaries、compactions、database queries、classification 和 coding subagent；Claude Code 2.1.293 已同步接入。GitHub Copilot 同日把 Haiku 5.5 纳入 Copilot，明确用于 subagents、quick edits 和 terminal tasks。citeturn3search0turn9view1turn7view2

这说明模型选择正在进入 Agent loop 内部：主 Agent 处理复杂规划和推理，小模型负责高频局部工作，成本和延迟优化由 Harness 调度完成。

### 3. 长任务运行时继续围绕恢复和状态一致性收敛

Gemini CLI 10 月 7 日 nightly 修复 resumed session 的重复 tool response、history 丢失和 untrusted workspace settings；LangGraph 延续 checkpoint replay / branch fork 修复并发布 CLI 0.4.33；Vercel AI SDK 7.0.132 新增 step-end persistence callback。citeturn9view2turn9view3

这些更新共同说明，Agent runtime 的核心问题正在从“如何调用模型”进入“如何可靠保存一次执行过程”：session resume、checkpoint、branch、stream persistence 和 deployment lifecycle 都成为 Harness 的一等状态。
