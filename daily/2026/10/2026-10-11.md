- **Source**：GitHub / Copilot Changelog
- **Title**：New controls and chat improvements in Copilot for JetBrains
- **发布时间**：2026-10-10
- **Topics**：MCP、Permissions、Tool Runtime、Model Governance、Coding Agent
- **Priority**：P2
- **Original**：https://github.blog/changelog/2026-10-10-new-controls-and-chat-improvements-in-copilot-for-jetbrains/
- **What changed**：新增 MCP Server 自动启动控制，可禁止 Copilot 与 Claude 自动启动已配置的 MCP Server；企业管理员可以设置新 Agent 会话的默认模型。
- **Technical details**：MCP 服务的配置、启动和单次工具授权属于不同生命周期阶段；新控制将“已经配置”和“自动启动”分离。默认模型只影响新会话初始选择，不取消用户显式切换能力。其他修复涉及语言服务器、MCP 配置、工作区、worktree 和会话可靠性，没有披露新的协议或沙箱语义。
- **Why it matters**：IDE Agent 宿主应区分工具发现、服务激活与工具调用授权；启动控制不能代替每次调用的权限检查。
- **是否值得阅读全文**：持续观察。
