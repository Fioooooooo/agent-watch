# Agent 一手情报｜2026-10-05

## 每日摘要

今天最明确的技术变化是：**Coding Agent 的运行时正在把长任务可靠性、上下文管理和协议互操作做成默认基础设施。**

Gemini CLI 在 2026 年 10 月 2 日的 nightly 中加入 append-only delta patching、bounded history windowing、原子状态持久化与损坏恢复、活动操作取消处理；10 月 3 日继续修复交互确认。Qwen Code 在 10 月 4 日的 nightly 同时修复 Code Mode 与 lazy tool discovery 的文本对齐、跨目录工具调用权限、daemon extension settings 隔离，并继续覆盖 managed-agent 相关测试。两条线都直接落在 Harness 核心边界：上下文如何增量维护、工具如何按需暴露、权限如何跨目录生效、进程状态如何恢复。

Codex 官方 Releases 在 10 月 2–4 日连续发布 `0.162.0-alpha` 多个预览版本，最新看到 `0.162.0-alpha.13`。页面公开说明有限，当前更适合作为高频运行时迭代和兼容性验证信号持续观察，而不能据此推断具体的 Agent loop 或权限架构变化。

最值得阅读全文的是 Gemini CLI 与 Qwen Code 的 Release Notes；Codex 预览版只需持续观察。

## 完整材料

### 1. Gemini CLI：增量记录、历史窗口、原子持久化与恢复能力继续下沉到核心运行时

- **Source**：Google / Gemini CLI
- **Title**：`v0.64.0-nightly.20261002.gc9096a847`、`v0.64.0-nightly.20261003.gfb972b2f8`
- **发布时间**：2026-10-02、2026-10-03
- **Topics**：Context Engineering、Recovery、Checkpoint、Persistence、ACP、A2A、Tool Runtime
- **Priority**：P1
- **Original**：
  - https://github.com/google-gemini/gemini-cli/releases/tag/v0.64.0-nightly.20261002.gc9096a847
  - https://github.com/google-gemini/gemini-cli/releases/tag/v0.64.0-nightly.20261003.gfb972b2f8
- **What changed**：10 月 2 日版本加入 ChatRecordingService 的 append-only delta patching 与 bounded history windowing；CLI 状态改为原子持久化，并在数据损坏时从备份恢复；活动操作中的 Ctrl+C 能到达取消处理器。10 月 3 日版本继续修复交互选择确认。
- **Technical details**：
  - 通过追加式 delta 记录减少整段会话重写；
  - 通过 bounded history window 控制长期对话的历史体积；
  - 原子写入与备份恢复降低进程中断或文件损坏后的状态丢失；
  - 取消信号被明确接入活动操作处理链；
  - 同一 Release 序列还出现 A2A V1→V2 设置迁移、ACP `usage_update` 通知和非交互 autonomous plan execution。
- **Why it matters**：长时间运行 Agent 的关键不只是模型能力，而是上下文是否能增量维护、状态是否能安全落盘、任务是否能取消和恢复。Gemini CLI 正在把这些能力做成核心运行时。
- **是否值得阅读全文**：是

### 2. Qwen Code nightly：lazy tool discovery、跨目录权限与 daemon 状态隔离继续收敛

- **Source**：Qwen / Qwen Code
- **Title**：`v0.24.7-nightly.20261004.9915c7ff8f`
- **发布时间**：2026-10-04
- **Topics**：Tool Discovery、Permissions、Daemon Runtime、Managed Agent、Context Efficiency
- **Priority**：P1
- **Original**：https://github.com/QwenLM/qwen-code/releases/tag/v0.24.7-nightly.20261004.9915c7ff8f
- **What changed**：修复 Code Mode 文本与 lazy tool discovery 的对齐；让已批准的跨目录工具调用真正遵循权限；将 daemon extension settings 的加载与共享进程状态隔离；继续补充 managed-agent 测试。
- **Technical details**：
  - 工具发现从启动时静态加载转向按需发现后，系统提示和 Code Mode 文本必须保持一致；
  - 跨目录调用需要把批准状态与实际路径校验连接起来；
  - daemon 扩展配置不再直接污染共享进程状态，降低多 workspace / 多会话之间的串扰；
  - managed-agent 相关测试继续覆盖运行时边界。
- **Why it matters**：工具面、权限和 daemon 状态是 Coding Agent 最容易出现隐性耦合的三个区域。Qwen Code 的连续修复说明 Harness 正在把这些边界拆开，并为托管执行和多工作区场景建立更稳定的语义。
- **是否值得阅读全文**：是
